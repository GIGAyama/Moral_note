# こころスコープ（Moral_note）

道徳の時間に、児童一人ひとりの考えを**授業の前と後の2回**集めて、
その変化を1枚の散布図で見られるようにした、小学校向けの無償アプリです。

- 案内ページ … <https://moral-note.giga-school.com/>
- 動くところ … Google Apps Script（先生おひとりずつが、ご自分のアカウントで公開します）
- ライセンス … MIT

> **共通の入口はありません。**
> 先生がご自分の Google アカウントで公開し、その URL を学級に配って使います。
> 児童の記述は、公開した先生ご自身のドライブにあるスプレッドシート1つに入ります。

---

## 入れかた

**A（おすすめ）と B のどちらか**です。入るものは同じです。

### A. スプレッドシートをコピーする

コードもデータも1つのファイルに入っているので、貼り付ける作業がありません。

1. **[スプレッドシートをコピーする](https://docs.google.com/spreadsheets/d/1AA9q9FhjoT3JVDpNRJPshx4_QAv87uN-jjmqBRw2p4E/copy)** を開き、「コピーを作成」を選びます。
2. できたファイルを開き、「拡張機能」＞「Apps Script」を開きます。
3. 「デプロイ」＞「新しいデプロイ」＞種類は「ウェブアプリ」。
   - 実行するユーザー … **自分**
   - アクセスできるユーザー … **同一ドメインの全員**
4. 表示された URL を児童に配れば準備完了です。

> 学校のポリシーで「外部のファイルのコピー」が禁じられていると、手順1で止まります。
> その場合は B をお使いください。

### B. ファイルを貼り付ける

1. 児童の記録を入れるスプレッドシートを新しく作ります（名前は何でも構いません）。
2. 「拡張機能」＞「Apps Script」を開きます。
3. 既定の `コード.gs` の中身を消し、このリポジトリの `code.gs` を貼り付けます。
4. 「＋」＞「スクリプト」で `Gemini.gs` を足し、中身を貼り付けます。
5. 「＋」＞「HTML」で4つ作り、名前を `app-shell` / `css` / `js` / `js_patterns` にして、
   それぞれ同名の `.html` の中身を貼り付けます。
   - **`index.html` は貼らないでください。** あれは案内ページで、GAS では使いません。
6. A の手順3・4と同じようにデプロイします。

## 最初に確かめること

1. 公開した URL を、**ご自分のアカウント**で開きます。そのまま先生用の画面に入れます。
   - 先生かどうかは、**アプリを公開したご本人か**で判定しています。
     初期設定の実行は要りません。
2. スプレッドシートを開き、上のメニューに「こころスコープ」が出ることを確かめます。
   「シートを点検する」で「シートの作りは想定どおりです」と出れば準備完了です。
3. 児童に URL を配ります。

### 先生が複数いる場合

Apps Script の「プロジェクトの設定」＞「スクリプト プロパティ」に
`TEACHER_EMAILS` を作り、メールアドレスをカンマ区切りで並べてください。

```
sato@example.ed.jp,suzuki@example.ed.jp
```

**`TEACHER_EMAILS` を設定すると、そこに載っている人だけが先生になります。**
公開したご本人も、忘れずに入れてください。

## スプレッドシートの扱い

このアプリは、シートを**列の番号**で読み書きしています。
たとえば「記録」シートの3列目は児童ID、5列目はスライダーの数値、8列目は削除の印です。

**列を挿したり、並べ替えたりしないでください。**
名前の誤字を直す、いらない行を消す、といった操作は構いません。

| してよいこと | しないでほしいこと |
|---|---|
| 名簿の氏名・ふりがなを直す | 列を挿す・消す・並べ替える |
| いらない行を消す | シートの名前を変える |
| 自分用のシートを新しく足す | 1行目の見出しを書き替える |

列がずれると、**画面にエラーを1つも出さないまま**次のことが起きます。

- 散布図の点が全部ずれる
- 消したはずの記録が戻る（削除の印が別の列になるため）
- 「すでに送信済みです」が出なくなり、同じ児童の記録が二重に入る

### 点検と修整

スプレッドシートのメニュー「こころスコープ」から使えます。

| メニュー | すること |
|---|---|
| シートを点検する | 想定どおりかを見ます。**何も書き換えません。** |
| 直せるところを直す | 消えたシート・空のままの見出しを書き足します。 |

**「直せるところを直す」は、列がずれているシートには1列も触りません。**
見出しだけを正しく直すと「間違った列に正しい名前が付いた」状態になり、
ずれていること自体が見えなくなるからです。
そういうときは、どこがどうずれているかだけをお伝えします。直すのは人の仕事です。

## 児童に見えるもの・見えないもの

| もの | 児童 | 先生 |
|---|---|---|
| 名簿の全員ぶん（氏名・ふりがな・メール） | ✕ | ○ |
| 自分の記録（マイページ） | ○ | ○ |
| ほかの子の記録（氏名つき） | ✕ | ○ |
| **いま行われている授業**の、名前を伏せた記述 | ○ | ○ |
| **終わった授業**の記述 | ✕ | ○ |
| 授業の作成・切り替え・CSV書き出し | ✕ | ○ |

判定はすべてサーバー側（`code.gs`）で行っています。画面のボタンを隠すだけの
作りにはしていません。

## 開発

```bash
npm run check     # このリポジトリの点検（構文・配線・公開関数・案内ページ）
npm test          # シートの点検・修整のテスト
```

`npm run check` は `main` への push で走る自動反映（`.github/workflows/deploy.yml`）の
前段でも回ります。**ここが赤いと GAS へは反映されません。**

| ファイル | 役割 |
|---|---|
| `code.gs` | バックエンド。シートの定義（`SHEETS_`）と点検・修整もここ |
| `Gemini.gs` | 生成AIの呼び出し（[正本](https://github.com/GIGAyama/GIGAyama.github.io/blob/main/standards/gas/Gemini.gs)のコピー） |
| `app-shell.html` | GAS の画面の外枠。`doGet` が読みます |
| `css` / `js` / `js_patterns`.html | 画面の中身 |
| `index.html` | **案内ページ**（moral-note.giga-school.com）。GAS へは送りません |
| `docs/copy-distribution.md` | コピー用テンプレートの作り方（作者向け） |

### 配り方について

このアプリは**コンテナバインド**（スプレッドシートにスクリプトが束ねられた形）で
動きます。独立スクリプトとして公開済みの学級もそのまま動きます
（`getDB()` が両方を見分けます）。くわしくは
[docs/copy-distribution.md](docs/copy-distribution.md) にあります。
