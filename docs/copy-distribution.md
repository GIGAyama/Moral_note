# スプレッドシートのコピーで配る（作者向けの手順）

このアプリは、児童の記録を入れるスプレッドシートにスクリプトが束ねられた状態
（コンテナバインド）でも、独立スクリプトでも動きます。`code.gs` の
`getDB()` がどちらかを見分けます。

コピーで配ると、先生の手数が **5ファイル貼り付け → デプロイ** から
**コピー → デプロイ** に減ります。この文書は、そのテンプレートを作る手順です。

> **この作業は、Google アカウントを持つ人にしかできません。**
> リポジトリの側からは用意できないので、ここに手順だけ置いてあります。

---

## 1. テンプレートを作る

1. 新しいスプレッドシートを作り、名前を **「こころスコープ」** にする。
   （コピーすると「こころスコープ のコピー」になります。先生が名前を変えても構いません。）
2. シートは作らなくてよい。**最初に開かれたときに `ensureSheets_()` が
   「設定」「名簿」「授業」「記録」「単元」を作ります。**
   先に作るなら、見出し行は `code.gs` の `SHEETS_` と同じにすること。
3. 「拡張機能」＞「Apps Script」を開く。
4. 既定の `コード.gs` の中身を消し、リポジトリの `code.gs` を貼り付ける。
   ファイル名は `コード` のままでよい（`.gs` の名前は動作に関係しません）。
5. 同じように `Gemini.gs` を足す。
6. 「＋」＞「HTML」で4つ作り、名前を **`app-shell` / `css` / `js` / `js_patterns`** にする。
   それぞれリポジトリの同名 `.html` の中身を貼り付ける。
   **`index.html` は貼らないこと。** あれは moral-note.giga-school.com に出す案内ページで、
   GAS では使いません（`.claspignore` でも送らないようにしてあります）。
7. いったん保存する。**デプロイはしない**（デプロイはコピーには付いてこないので、
   ここで作っても意味がありません）。

## 2. 中身を空にしておく

**テンプレートに残っているものは、コピーした全員に配られます。**

- 試しに入れた児童名・記述・授業を消す
- スクリプトのプロパティに何も入っていないことを確認する
  （「プロジェクトの設定」＞「スクリプト プロパティ」）。とくに
  `OWNER_EMAIL` / `TEACHER_EMAILS` / `GEMINI_API_KEY` / `TEACHER_PASSWORD_HASH` /
  `DB_ID` が残っていないこと。

> スクリプトのプロパティは**コピーされません**が、テンプレート側に残っていないことは
> 確かめておいてください。とくに `GEMINI_API_KEY` は、残っていると
> **あなたの課金キーが、コピーした全員に配られたのと同じ**になります。

## 3. 共有の設定

1. スプレッドシートの「共有」を開く。
2. 一般的なアクセスを **「リンクを知っている全員」＋「閲覧者」** にする。
   - **「編集者」にしないこと。** 編集者にすると、コピーせずに直接書き込めてしまいます。
3. リンクをコピーする。次の形になっているはずです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/edit?usp=sharing
   ```

4. 末尾を **`/copy`** に置きかえたものが、配るリンクです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/copy
   ```

   これを開くと「コピーを作成」のダイアログがすぐ出ます。

## 4. リンクを貼ってある場所（2026-08-23 に設定済み）

配っているリンクは1つです。

```
https://docs.google.com/spreadsheets/d/1AA9q9FhjoT3JVDpNRJPshx4_QAv87uN-jjmqBRw2p4E/copy
```

| ファイル | 場所 |
|---|---|
| `index.html` | 「入れかた」のボタン |
| `README.md` | 「A. スプレッドシートをコピーする」の手順1 |

**テンプレートを作り直して ID が変わるときは、この表の両方を差し替えてください。**

差し替え漏れは `npm run check` が見つけます。

- 2か所の ID が食い違うと **`E_COPY_LINK_MISMATCH`** で落ちます。
  片方だけ見た先生が古いテンプレートをコピーするのを防ぐためです。
- どちらも `__COPY_LINK__` という目印に戻すと、**⏳ 人の手が要るもの** として
  毎回出ます（ゲートは緑のまま）。新しいテンプレートを用意している間の置き場所です。

## 5. 入れたあとに確かめること

手元では確かめられないので、実機で1回だけ見てください。

1. **別のアカウント**（できれば学校のアカウント）でコピーリンクを開き、コピーが作れるか。
   - **学校のドメインが「外部のファイルのコピー」を禁じていると、ここで止まります。**
     止まる場合は、貼り付けの手順（README の B）を案内し続けてください。
2. コピーしたファイルでデプロイし、URL を開いて画面が出るか。
3. コピーしたファイルの上のメニューに **「こころスコープ」** が出るか。
   「シートを点検する」を押して「シートの作りは想定どおりです」と出れば、見出しがそろっています。
   （このメニューは、スプレッドシートを開いたときに `onOpen` が作ります。
   独立スクリプトでは出ません。）
4. 授業を1つ作り、児童役で1件送り、**コピーしたそのファイル**の「記録」シートに行が増えるか。
5. **デプロイした本人が、そのまま先生用の画面に入れるか。**
   `manualSetup()` を実行していなくても入れます（`isTeacher_()` が
   公開した本人を見ます）。入れない場合は、アクセスできるユーザーの設定を確かめてください。
6. `moral-note.giga-school.com` を開き、案内ページが出るか
   （GAS のテンプレートがそのまま出るなら、`index.html` を取り違えています）。

## 6. すでに配ってある学級について

**前の配り方（独立スクリプト）で公開済みの学級は、そのままで動きます。**
`getDB()` は束ねられたファイルが無ければ、これまでどおりスクリプトプロパティ
`DB_ID` のスプレッドシートを開きます。記録は消えません。
`isTeacher_()` も `OWNER_EMAIL` を先に見るので、先生の判定も変わりません。

貼り直しをお願いするのは、`code.gs` の直しを届けたいときだけです。

### ひとつだけ変わったこと

**開けなかったときに、新しいスプレッドシートを作り直す動きをやめました。**

以前は `DB_ID` のファイルを開けないと、黙って新しいファイルを作って `DB_ID` を
差し替えていました。権限の足りない人が1回開くだけで、学級全員の記録が入った
ファイルから空のファイルへ静かに移り、画面には何も出ないまま
「記録が消えた」ようにしか見えませんでした。
いまは**作り直さずに、理由を出して止まります。**
