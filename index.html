こころスコープ

道徳の時間に、児童一人ひとりの考えを授業の前と後の2回集めて、 その変化を1枚の図で見られるようにした無償のアプリです。小学校の教員が作りました。

Google アカウントが1つあれば動きます。サーバーの費用も、外部サービスの契約もありません。

このページからは、授業を始められません

このアプリは、先生おひとりずつが、ご自分の Google アカウントで公開して使う形です。 みんなで使う共通の入口はありません。

  • 児童のみなさんは、先生から配られた URL を開いてください。このページではありません。
  • 先生方は、下の「入れかた」の手順で、ご自分の学級の URL を作ってください。

児童の記述は、公開した先生ご自身の Google ドライブにあるスプレッドシート1つに入ります。 制作者を含め、ほかの誰のところにもデータは行きません。

どんなアプリか

道徳の授業でいちばん見たいのは、答えそのものではなく「その子の考えが、授業のなかでどう動いたか」です。 けれども動いたかどうかは、ワークシートを回収して読み比べるまで分かりません。 1時間の終わりに 40 枚を読み比べる時間は、たいていありません。

このアプリは、同じ問いを授業の導入と振り返りの2回たずねます。 スライダーで気持ちの位置を、その下に理由を書いてもらいます。 2回ぶんがそろうと、先生の画面に散布図が出ます。 斜めの線から離れている点が、その時間で考えが動いた子です。 指名を決めるのにも、次の時間の入り口を決めるのにも使えます。

使うときの流れ

  1. 先生が授業（お題）を作り、URL を配ります。名簿はスプレッドシートに入れておきます。
  2. 導入：子どもたちがスライダーを動かし、そう思う理由を書いて送ります。
  3. 先生が「振り返りへ」に切り替えます。児童の画面もいっしょに切り替わります。
  4. 振り返り：同じ問いにもう一度答えます。導入で自分が書いたものが画面に出るので、 「さっきと変わったか」を自分で確かめながら書けます。
  5. 先生の画面の散布図で、学級全体の動きと、一人ひとりの動きを見ます。 名前を伏せた意見の一覧を電子黒板に映すこともできます。

ほかに、単元をあらかじめ登録しておく機能、児童が自分の記録をふり返る「マイページ」、 1時間ぶんを CSV に書き出す機能があります。

入れかた

準備するものは Google アカウント1つ。ふだんお使いの学校のアカウントで構いません。 配っているスプレッドシートをコピーして、公開の設定をするだけです。

スプレッドシートをコピーして始める 手順の全文（README）
  1. 上のボタンを押し、「コピーを作成」を選びます。ご自分のドライブにファイルができます。
  2. できたファイルを開き、上の「拡張機能」＞「Apps Script」を開きます。
  3. 右上の「デプロイ」＞「新しいデプロイ」＞種類は「ウェブアプリ」。 実行するユーザーは「自分」、アクセスできるユーザーは 「同一ドメインの全員」をおすすめします。
  4. 表示された URL を児童に配れば準備完了です。

コードは、コピーしたファイルの中に入っています。 貼り付ける作業はありません。児童の記述もそのファイルの中に入るので、 「データはどこにできたのか」を探す必要もありません。

先生用の画面は、公開したご本人だけが開けます。 アプリを公開した Google アカウントで開けば、そのまま先生として入れます。 学年で分担するなど先生が複数いる場合は、Apps Script の 「プロジェクトの設定」＞「スクリプト プロパティ」に TEACHER_EMAILS を作り、 メールアドレスをカンマ区切りで並べてください。

コピーできないときは、貼り付けでも入ります。 学校のポリシーで、外部のファイルのコピーが禁じられていることがあります。 その場合は README の「B. ファイルを貼り付ける」 をご覧ください。code.gs などを Apps Script に貼る手順で、入るものは同じです。

アクセスできるユーザーに「全員（匿名ユーザーを含む）」を選ばないでください。 URL を知っていれば校外の人でも書き込めてしまいます。 道徳のノートには、家庭のことや、友だちとのもめごとが書かれます。 「同一ドメインの全員」でお使いください。

シートを点検する

コピーしたスプレッドシートを開くと、上のメニューに「こころスコープ」が出ます。

  • シートを点検する…… 中の作りがアプリの想定どおりかを見ます。何も書き換えません。
  • 直せるところを直す…… 消えてしまったシートや、空のままの見出しを書き足します。

児童ID・スライダーの数値・削除の印は、列の番号で読み書きしています。 名前の誤字を直したり、行を消したりしていただくのは構いませんが、 列を挿したり、並べ替えたりしないでください。 散布図が静かにずれたり、消したはずの記録が戻ったりします。

列がずれていることに気づいた場合、アプリは見出しを勝手に書き直しません。 書き直すと「間違った列に正しい名前が付いた」状態になり、ずれていること自体が 見えなくなるからです。どこがどうずれているかだけをお伝えします。

できないこと

正直に書いておきます。オフラインでは使えません。 児童の画面は一定の間隔で先生の画面に追いつく形なので、切り替えが数秒遅れることがあります。 1つのスプレッドシートは1学級ぶんです。 複数の学級でお使いになる場合は、学級のぶんだけコピーして、それぞれ公開してください。 アプリの中から名簿を一括で読み込む口はありますが、 校務システムからの取り込みには対応していません。
